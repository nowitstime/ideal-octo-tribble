# Feedback

One file per screen. After each play test on the Pixel, add dated notes to the screens you played, and a line to the session log below.

Each screen file has:

- **How it plays:** what the screen does today, in a few lines.
- **Questions:** things to answer while playing. Cross them off or move the answer into Notes.
- **Notes:** dated, newest first, in your words.
- **Decided:** things settled, so they don't get reopened.
- **Next:** what to change before the next play test.

Screens: [map](map.md) · [drums](drums.md) · [chords](chords.md) · [bass](bass.md) · [lead](lead.md) · [progression](progression.md)
